# StandRise iOS Build (iPhone 6s+)

Автоматическая сборка `.ipa` игры **StandRise** (версия 1.0.0, Unity 2021.3) для iOS с использованием GitHub Actions (macOS 14 runner).

## Поддерживаемые устройства:
- iPhone 6s, 6s Plus, SE 1-го поколения
- iPhone 7, 7 Plus, 8, 8 Plus, iPhone X
- iPhone XS, XR, 11, 12, 13, 14, 15, 16 (все модели)
- iPad (начиная с iPad Air 2 / iPad mini 4)
- Минимальная версия iOS: 12.0+
- Архитектура: ARM64

## Установка:
Готовый файл `StandRise.ipa` можно скачать в разделе **Releases** или **Actions Artifacts** и установить через:
- TrollStore (iOS 14.0 — 15.8.3 без переподписи)
- Scarlet
- Sideloadly / AltStore
